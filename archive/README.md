# Historical notebooks and outputs

The earlier research artifacts are preserved here:

- `ngt_linformer_nodes_aligned_outputs/`: historical Linformer notebook and runs.
- `ngt_mha_nodes_aligned_outputs/`: earlier MHA notebook and runs.
- `diagnostic_notebooks/`: exploratory diagnostics.
- `analysis/`: earlier dated analysis snapshots.
- `eval_quality.py`: historical standalone evaluation entry point.

Original run names and data are preserved. Historical notebook cells and notes
can still describe the earlier directory layout. Current executable projects
and entry-point documentation live at the repository root and under `../docs/`.
